Where The Numbers Actually Come From

Simulated platform-level source data

Every number in the campaign workbook and the Agent Execution demo reconciles back to one of these 7 platforms. This page simulates what each platform's own native analytics view would show — the "before" picture, ahead of any AI tool touching it.

How The Data Actually Flows

Platform → Extraction Tool → This Dataset

An AI agent — the same canonical read_spend_data() tool function from the Measure & Optimise agent — visits each platform below, and the correct real tool for that platform's API pulls the raw numbers into one normalised layer, matching how the Data Aggregation Gateway is described on the Helicopter View. Note: the sheet these land in is a reporting layer, not a CRM — HubSpot/Salesforce (see the Tool Stack) is the actual downstream CRM for leads and contacts, a separate system.
