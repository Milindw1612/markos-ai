Where The Numbers Actually Come From

Simulated platform-level source data

Every number in the campaign workbook reconciles back to one of these 7 platforms — extracted directly by MarkOS's own AI agents, not a vendor tool stack. This page simulates what each platform's own native analytics view would show — the "before" picture, ahead of any AI tool touching it.

How The Data Actually Flows

Platform → Extraction Tool → This Dataset

An AI agent — the same canonical read_spend_data() tool function from the Measure & Optimise agent — visits each of the 5 ad platforms below and pulls the raw numbers directly via that platform's own native API, no vendor aggregator in between, matching how the Data Aggregation Gateway is described on the Helicopter View. Note: the sheet these land in is a reporting layer, not a CRM — HubSpot/Salesforce (see the Tool Stack) is the actual downstream CRM for leads and contacts, a separate system. Note: a vendor like Supermetrics/Funnel.io still earns its keep at higher scale — many more platforms, or many client accounts — but for a bounded core set like these 5 channels, the agent calling each API directly is simpler to run and cheaper to maintain than licensing a data-aggregation layer to do it (see the Tool Stack's Data Aggregation card for where that line sits).

From Data To A Decision

How the recommendation engine decides

Every campaign × channel block below carries a bid strategy, a current bid value, and one of 6 recommended actions — Continue, Hold, Add More Funds, Decrease Bid, Withdraw / Pause, or Change Creative. None of it is a separate AI call: it's one small, deterministic rule set running on the same real ROAS and trend numbers already reconciled with the workbook. This is the walkthrough of that rule set.

Add More FundsStrong & still improving — raise the bid or budget while it's working.
ContinueAt or above target, stable — no change needed this cycle.
HoldBorderline, flat trend — not enough signal yet either way.
Change CreativeStill healthy but declining — more likely fatigue than a bid problem.
Decrease BidBelow target and declining — pull back before it needs a pause.
Withdraw / PauseNear or below breakeven and still falling — stop the spend now.
