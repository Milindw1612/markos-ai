How this works — a ready reference

The loop: a reasoning step (Claude) decides which tool to call next, the tool executes and returns real evidence, and control passes back to reasoning — this repeats until enough evidence exists to produce a recommendation. Nothing is pre-scripted; the sequence above is what one real run actually did.

What each tool stands in for: these are canonical functions, not one-vendor integrations — read_spend_data could call Supermetrics or Funnel.io behind the scenes, call_mmm_model could call Google Meridian or Meta Robyn, depending on which vendor a real deployment is wired to. Swapping the vendor means changing what's inside the function, not the agent or the graph around it.

Why LinkedIn gets PAUSE and the others get DECREASE: the bid tool compares each channel's most recent 3-day ROAS against a 3.0x target. LinkedIn's recent ROAS (1.30) is furthest below target and its blended performance is worst overall (-24% vs. the account average) — the tool's own threshold logic proposes a full pause rather than a partial cut. The other three are also underperforming their recent target, hence DECREASE, but none has fallen as far as LinkedIn.

What's real vs. pending: every number in the scorecard and every tool call in the trace above is a genuine function output, run against the actual mock dataset — nothing there is written or guessed. The one thing not yet real is the final recommendation card's narrative text, which needs an actual Claude API call to generate; it's marked pending rather than faked, and this page will be updated with the real output the first time that run happens.
