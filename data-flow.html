Putting It All Together

How the five pieces connect

Each section below shows one cluster in isolation. This is the same data, wired into a single loop — so it's clear how a post going live turns into spend data, how a recommendation card becomes a line in a board report, and where the AI layer actually sits in that chain.

Read left to right, top to bottom: Plan & Create turns a brief into creative and scheduled posts; once those go live the resulting spend and performance data is exactly what feeds Measure & Optimise's bid and MMM tools. Convert & Retain runs in parallel off the same Gateway feed. All three report into Report & Lead, which trades computed metrics for narrative with the AI Assistant Layer before the combined dashboard and report package reaches the Director — who takes it from there into the CMO → CEO → Board cascade on the Helicopter View.
